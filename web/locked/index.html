This NAS is locked

Setup is complete, but the KeePassXC database has not been unlocked since the appliance started. Sign-in, Cockpit, files and applications stay unavailable until it is.

Unlock from the recovery console

  1. Use the local console, SSH with a provisioned recovery key, or hardware KVM.
  2. Sign in as the local recovery administrator. An Authentik account alone cannot unlock the NAS.
  3. Run sudo nas-secrets activate and enter the KeePassXC database password at its prompt.
  4. Reload this page after activation reports success.

If activation fails, follow the locked-state troubleshooting steps in the operator manual.
