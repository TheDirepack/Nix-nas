# Project documents

The deployed mdBook includes only current operator-facing project documents. Development notes, code maps, active backlog, and decision history remain in the source tree under `docs/development/` and are intentionally excluded from the appliance UI.

Current project references:

- README: scope, ownership boundaries, installation entry point, and validation commands.
- Security model: trust boundaries and secret/authorization rules.
- Recovery runbook: ordered recovery procedures and verification.
- Changelog: user-visible release changes.

Generated command, option, configuration, UI, and upstream-help pages are listed separately in this book.
