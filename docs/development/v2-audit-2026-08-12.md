## 2. Custom code that duplicates tested upstream (replace)

### 2.1 Podman networks + VLAN/VRF — 514 lines
**File:** `services/nas_v2_podman_network.py:1`
**Duplicates:** `virtualisation.quadlet.networks` (NixOS 25.11, `nixpkgs/nixos/modules/virtualisation/quadlet.nix`) and `home-manager/modules/services/podman-linux/networks.nix` which already generate `*.network` Quadlet with `Driver=bridge`, `Internal=true`, `Options=isolate=strict`, `NetworkName=`, `InterfaceName=` and handle `dns_enabled` + firewall `networking.firewall.interfaces.<iface>.allowedTCPPorts`.
**Online evidence:** `mynixos.com/options/services.podman.networks.<name>` and `github.com/SEIAROTg/quadlet-nix` (5k stars, tested) show declarative `virtualisation.quadlet.networks.<name> = { driver = "bridge"; subnet = "10.0.123.0/24"; }` generates the same `Network=` reference and systemd `Requires`/`After` automatically. No need for `bridge_interface_name()` hash or `nmcli --offline` VRF code.
**Action:** Delete `nas_v2_podman_network.py:31` (`bridge_interface_name`, `vlan_binding` 90 lines, `_vlan_profile_sources` 60 lines, `_ensure_vlan_resource` 40 lines). Replace with `networking.vlans.<name> = { id = 42; interface = "eno1"; }` + `systemd.network.networks` and let `virtualisation.quadlet.networks.<name>.extraConfig.Network.VRF = "nv2vrf..."` if needed. Keep thin `network_policy()` + `requires_firewalld()` (30 lines) as pure validation.

### 2.2 Firewalld — 424 lines
**File:** `services/nas_v2_firewalld.py:1`
**Duplicates:** `networking.firewall` (`allowedTCPPorts`, `allowedUDPPorts`, `extraCommands` with `iptables -A nixos-fw ...`) and `services.firewalld.zones`/`policies` (NixOS `nixos/modules/services/networking/firewalld.nix`). Upstream `firewalld` already validates with `firewall-offline-cmd --check-config`.
**Action:** Delete `nas_v2_firewalld.py:261` (`compile_projection` 120 lines, `_host_policy_xml` etc.). Replace with a 30-line `systemd` generator that reads `/run/nas-control/effective.json` via `jq -r '.services[] | .listeners[] | .exposure.port'` and writes `/run/nas-control/firewall-ports.json`, then `networking.firewall.allowedTCPPorts = builtins.fromJSON (builtins.readFile /run/nas-control/firewall-ports.json)` at activation (or `extraCommands`).

### 2.3 Accelerator/GPU — 280 → 80 lines (done in `d114dc4`)
**File:** `services/nas_v2_accelerator.py:1`
**Duplicates:** `hardware.nvidia.modesetting`, `hardware.opengl`, `hardware.graphics`, `services.xserver.videoDrivers = ["nvidia"]`, and `virtualisation.containers.cdi.sources = [ pkgs.nvidia-container-toolkit ]` which expose `nvidia.com/gpu` CDI and `/dev/dri` without Python. `is_cdi_selector` is just `^[A-Za-z0-9][A-Za-z0-9_.-]*/...` regex.

### 2.4 Sessions — 403+426 lines

No need for custom `nas_v2_session` DB, `nas_v2_wake.py` can call `systemd-run` directly.
**Action:** Delete both, keep only `nas_v2_wake.py:1` as thin `forward_auth` → `systemd-run` (50 lines). Use `virtualisation.oci-containers` with `autoStart = false` for on-demand.

### 2.5 Backup — ~250 lines

### 2.6 Caddy — 405 lines
**File:** `services/nas_v2_caddy.py:1`
**Duplicates:** `services.caddy.virtualHosts.<host>.extraConfig` + `services.caddy.globalConfig` (NixOS `nixos/modules/services/web-servers/caddy/default.nix`) already does `caddy fmt` and `caddy reload`. ### 2.7 Compose/Quadlet/Libvirt — 437+415+340 lines
**Duplicates:** `virtualisation.oci-containers`, `virtualisation.quadlet.containers`, `virtualisation.libvirtd` (NixOS). These modules already handle `systemd` unit generation, `DeviceAllow`, `Restart`, etc.
**Action:** Make `nas_v2_compose.py`, `nas_v2_quadlet.py`, `nas_v2_libvirt.py` thin shims (100 lines each) that just copy `source` Quadlet/compose XML to `output_dir` and add `PartOf=`; don't re-implement `systemd` lowering.

### 2.8 Systemd core — 844 lines
**File:** `services/nas_v2_systemd.py:1`
**Duplicates:** `systemd.services.<name>.serviceConfig` + `systemd.timers` (NixOS) for `Restart`, `TimeoutStartSec`, `DeviceAllow`, `ReadOnlyRoot`, etc. The custom `daemon-reload`/`link`/`unlink` in `nas_v2_systemd_reconcile.py:1` duplicates `systemd`'s `systemctl daemon-reload` and `systemd` generator.
**Action:** Keep only dependency/topology (`requires_firewalld`, `network_policy`) and readiness (`nas_v2_readiness.py:1`). Delegate `DeviceAllow`, `MemoryHigh`, `NoNewPrivileges` to Nix `systemd.services`.
